# antix1 monitoring (Prometheus + node_exporter + Grafana OSS, runit)

| svc (/etc/sv)  | listen            | user          | data                    | logs (svlogd)                  |
|----------------|-------------------|---------------|-------------------------|--------------------------------|
| node-exporter  | 127.0.0.1:9100    | node_exporter | /var/lib/node_exporter  | /var/log/monitoring/node-exporter |
| prometheus     | 127.0.0.1:9090    | prometheus    | /var/lib/prometheus (30d) | /var/log/monitoring/prometheus |
| grafana        | 100.96.0.5:3000 (CloudflareWARP mesh only) | grafana | /var/lib/grafana | /var/log/monitoring/grafana |

Upstream binaries only (sha256-verified): Prometheus 3.16.0 and node_exporter 1.13.1 from the
GitHub release tarballs, Grafana OSS 13.3.1 tarball from dl.grafana.com into /opt/grafana-<ver>
(/opt/grafana symlink). The Grafana .deb hard-depends on systemd, so it is not used here.

Scrape targets: prometheus, node, grafana (/metrics), incus (https://100.96.0.5:8443/1.0/metrics,
metrics-only trust cert `prometheus-antix1`, key in /etc/prometheus/tls). op-grpc-bridge / op-web
expose no Prometheus endpoint.

Grafana: admin user `admin`, password in root-only /root/grafana-admin-password (generated by
install.sh, never committed). Sign-up, org creation and anonymous access are disabled. Datasource
`Prometheus` (uid prometheus) and dashboards in folder antix1 are file-provisioned:
Node Exporter Full (grafana.com 1860), Prometheus 2.0 Overview (3662), Incus (19727, Loki panels dropped).
Remote access: WARP mesh, or `ssh -L 3000:100.96.0.5:3000 root@188.68.58.237`.

Re-install / upgrade: download + verify tarballs into DL_DIR, extract, re-run
`prep-dashboards.py` if dashboards change, then `sh install.sh DL_DIR` and `sv restart <svc>`.
