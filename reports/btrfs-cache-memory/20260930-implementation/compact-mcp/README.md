The proposal files contain the `tched_router.config_patch` request object (`{"operations":[...]}`), not a bare JSON Patch array. It preserves `/mcp?opdbus_mode=compact`. It is **not applied**: the current task scope has no admitted native config write. The inverse patch tests the same server identity and corrected URL before restoring the previous hostname exactly.
